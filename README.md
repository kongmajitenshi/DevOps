### 4주차
- '2'는 오류
- '/dev/null'은 쓰레기통(대충)
- 파이프 ('|'): 앞에 있었던 표준 출력을 뒷 명령어의 표준 입력으로 넣어줌.
- 'grep -R -n "exit 1" week03 | wc -l' 하면 'grep ... "week03"'의 출력을 'wc -l'의 입력으로
- '>' 앞에 1이 숨어있는 것. 원래는 '1>'형태인데, 그냥 생략.
- '&': 백그라운드 실행
- '$?': 직전에 실행한 명령어의 종료상태 체크. 0인 경우 끝난거임.
